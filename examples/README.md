# Examples

| path | what |
|------|------|
| [`claude-code/settings.json`](claude-code/settings.json) | Hook registration for Claude Code (what `sentinel init --claude-code` writes) |
| [`codex/hooks.json`](codex/hooks.json) | Hook registration for the Codex CLI |
| [`generic/guard.sh`](generic/guard.sh) | Gate commands in a shell script with `sentinel check` exit codes |
| [`generic/guard.py`](generic/guard.py) | Gate tool calls in your own Python agent with `sentinel hook generic` |

See [docs/integrations.md](../docs/integrations.md) for the protocols.
